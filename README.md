# Арена переговоров

Тренажёр переговоров для молодых специалистов и сотрудников проектных команд. Пользователь выбирает или настраивает сценарий, ведёт диалог с LLM-собеседником и после диалога получает разбор по методике: SPIN, Гарвардский метод или свободный режим.

Проект команды «Магнит инноваций» для задачи №9 ЛЦТ-2026 (ОЭЗ «Алабуга»).

## Как устроено

- После каждой реплики LLM размечает ход пользователя: вопрос об интересах, объективный критерий, конкретное предложение, давление и т. д.
- Разметка двигает скрытые счётчики собеседника: доверие, готовность уступить, раздражение. Уступает собеседник или нет, решают счётчики, LLM только формулирует ответ. Одинаковые ходы дают одинаковый исход.
- После диалога судья-LLM ставит оценки 0–100 по осям выбранного метода и разбирает 2–3 ключевых момента.
- Если LLM недоступна, тренажёр работает на правилах.

Стек: FastAPI, SQLAlchemy, Postgres, LiteLLM и Instructor (любой провайдер LLM), React и Vite.

## Запуск

Нужны Python 3.12+ и Node.js 20+ (проверено на Python 3.13 и Node 24), браузер — актуальные Chrome, Firefox, Edge или Safari.

`.env` лежит в корне репозитория, рядом с `docker-compose.yml`:

```bash
cp env.example .env   # укажите LLM_MODEL и LLM_API_KEY или OFFLINE_MODE=true
```

Docker:

```bash
docker compose up --build
```

Откройте http://localhost:8000.

Без Docker нужны два терминала. Бэкенд читает `.env` и из своей папки, и из корня репозитория.

Терминал 1, бэкенд (по умолчанию SQLite в `backend/arena.db`):

```bash
cd backend
python -m venv ../.venv && ../.venv/Scripts/activate   # Linux/macOS: source ../.venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Терминал 2, фронтенд (запросы к `/api` проксируются на порт 8000):

```bash
cd frontend
npm install
npm run dev   # http://localhost:5173
```

Тесты: `cd backend && python -m pytest`. Тесты работают в режиме без LLM на временной SQLite и не трогают `arena.db`.

`ADMIN_TOKEN` в `.env` включает права администратора: только с этим токеном (поле в форме сценария) можно фиксировать сценарий для сотрудников и менять зафиксированный.
